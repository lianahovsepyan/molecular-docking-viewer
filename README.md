# Molecular Docking and Visualization Tool

A Python and PyMOL-based pipeline for simulating molecular docking and visualizing 3D complexes.

## 🌐 Interactive 3D Web Viewer (Click to Open)
You can view, rotate, and analyze the 3D molecular structure directly in your browser without installing anything:
- **[👉 Բացել 3D Վիզուալիզատորը բրաուզերում (HTML Preview)](https://htmlpreview.github.io/?https://github.com/lianahovsepyan/molecular-docking-viewer/blob/main/index.html)**
- **[👉 Ուղիղ Mol* 3D Մոդել](https://molstar.org/viewer/?url=https://raw.githubusercontent.com/lianahovsepyan/molecular-docking-viewer/main/protein_clean.pdb)**
